# Bending Basics

## Terms
- **Take-up (gain):** amount of pipe consumed by the bend itself; subtract from measured length.
- **Shrink:** horizontal loss when a pipe is bent upward; add to vertical height.
- **Multiplier:** factor relating vertical rise to horizontal mark distance for a given angle.
- **Stub-up height:** vertical distance from floor to top of conduit.
- **Radius of bend:** centerline radius; typically 4×, 6×, or 10× conduit diameter.

## Steps for a 90° stub-up
1. Measure stub-up height.
2. Add shrink (≈ 2× conduit diameter for 90° with standard radius).
3. Mark pipe at that total from the end.
4. Place mark at bender arrow; bend to 90°.
5. Verify with level; adjust if over/under.

## Back-to-back 90°
- Measure center-to-center distance between pipes.
- Mark midpoint; bend each side so marks land at bender arrow.
- Keep bends parallel and plumb.

## Offset
- Two equal bends (e.g., 30°/30° or 45°/45°) to bypass an obstruction.
- Travel = obstruction depth ÷ sin(angle).
- Mark spacing = travel × multiplier? No — mark spacing = travel; bend locations separated by travel.
